# Звіт про виконану роботу

## Проєкт

**Resume Builder** — вебзастосунок для створення, редагування та експорту резюме.

## Реалізовано

- реєстрацію, вхід, вихід і відновлення пароля через email;
- профіль користувача з персональними даними та фотографією;
- ролі звичайного користувача, staff-адміністратора та superuser;
- каталог шаблонів: «Класичний», «IT» і «Менеджер»;
- створення, редагування, перегляд, архівацію та видалення резюме;
- додаткові секції резюме;
- клонування резюме для створення нової версії;
- попередній перегляд перед завантаженням;
- експорт у PDF, DOCX і TXT;
- публічні резюме після підтвердження адміністратором;
- новини та оголошення з категоріями, статусами, зображеннями й пошуком;
- адміністративне керування резюме, користувачами та новинами;
- журнал активності та індикатор онлайн-користувачів;
- адаптивні HTML-шаблони та налаштування теми й кольорів;
- CSRF-захист, сесії та обмеження доступу стандартними засобами Django;
- SMTP-конфігурацію через `.env` для відновлення пароля.

## Технічна реалізація

- Backend: Django, SQLite, Django ORM, Forms і Function-Based Views.
- Frontend: Django Templates, Bootstrap і власний responsive CSS.
- Файли: зображення профілів і новин зберігаються в `media/`.
- Експорт: ReportLab для PDF і python-docx для DOCX.
- Тести: автоматичні Django-тести для реєстрації, шаблонів, PDF, DOCX, клонування та `.env`.
