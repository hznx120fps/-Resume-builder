# Інструкція для скриншотів проєкту

Цей файл підказує, які екрани найкраще зафіксувати для презентації та захисту проєкту Resume Builder.

## Рекомендований порядок

### 1. Головна сторінка

Відкрийте:

```text
http://127.0.0.1:8000/
```

На скриншоті мають бути видні назва Resume Builder, опис можливостей, кнопка «Почати», популярні шаблони та останні новини.

### 2. Каталог шаблонів

Перейдіть до розділу «Шаблони» або відкрийте:

```text
http://127.0.0.1:8000/templates/
```

Зробіть один широкий скриншот, де видно всі три шаблони: «Класичний», «IT» і «Менеджер». Важливо, щоб були видні описи та блок «Як виглядатиме».

### 3. Реєстрація та вхід

Зробіть скриншот сторінки реєстрації та окремо сторінки входу. На сторінці входу бажано, щоб було видно посилання «Забули пароль?».

### 4. Створення резюме

Увійдіть до акаунта, виберіть шаблон і відкрийте форму створення резюме. Заповніть прикладом:

- імʼя та назва резюме;
- короткий опис;
- досвід роботи;
- освіта;
- навички;
- одна додаткова секція.

Зробіть скриншот форми з видимими полями та кнопкою «Зберегти».

### 5. Список резюме

Відкрийте «Мої резюме». На скриншоті мають бути видні збережене резюме, його статус, кнопки перегляду, редагування та клонування.

### 6. Попередній перегляд

Відкрийте сторінку резюме та натисніть «Попередній перегляд». Це один із найважливіших скриншотів: на ньому має бути видно готове резюме, додаткові секції та кнопки PDF/DOCX.

### 7. Експорт

Після відкриття попереднього перегляду натисніть «PDF» або «DOCX». Для звіту достатньо скриншота сторінки попереднього перегляду з кнопками експорту. Сам файл краще показати окремо, якщо викладач просить продемонструвати результат.

### 8. Профіль користувача

Відкрийте сторінку профілю. На скриншоті покажіть форму з особистими даними та завантаженням фотографії.

### 9. Новини

Відкрийте:

```text
http://127.0.0.1:8000/news/
```

Зробіть скриншот зі стрічкою новин. Бажано, щоб були видні заголовки про DOCX, попередній перегляд, клонування та адаптивну версію.

Якщо потрібно показати адмін-функції, увійдіть як адміністратор і зробіть окремий скриншот форми «Додати новину».

### 10. Адміністративна панель

Для демонстрації ролей зробіть скриншот кастомної адмін-панелі. На ньому бажано показати список резюме, статуси та кнопки керування.

## Найкращий мінімальний набір

Якщо потрібні лише 5–6 скриншотів, використайте:

1. Головна сторінка.
2. Каталог шаблонів.
3. Форма створення резюме.
4. Список збережених резюме.
5. Попередній перегляд резюме.
6. Новини або адміністративна панель.

## Як зробити якісні скриншоти

- використовуйте ширину браузера приблизно 1280 px;
- перед скриншотом прокрутіть сторінку на початок потрібного блоку;
- закрийте зайві вкладки та особисті дані;
- використовуйте демонстраційний акаунт, а не справжній пароль;
- для адаптивності додайте один скриншот із вузьким вікном або з телефона;
- називайте файли зрозуміло: `01-home.png`, `02-templates.png`, `03-resume-preview.png`.

## Важливо для захисту

Не фотографуйте файл `pasword.txt` і не показуйте паролі, email-паролі або секретний `.env` на скриншотах. Для демонстрації використовуйте тестові дані.
